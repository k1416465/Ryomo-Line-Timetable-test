佐野駅電光掲示板 更新ファイル

現在の app.py は変更不要です。

以下の3つを、現在のプロジェクトに上書きしてください。
1. trains.json
2. templates/index.html
3. static/style.css

その後、コマンドプロンプトで:
py -3.12 app.py

ブラウザ:
http://127.0.0.1:5000

仕様:
- 1番線＝高崎・桐生方面
- 2番線＝小山方面
- 各番線は直近2列車を表示
- 備考枠は直近1列車のみ
- 「普通」は白背景＋黒文字＋白枠
- 4両は緑、6両はオレンジ
- 両数と残り時間は数字を大きく、「両」「分後」は小さく
- 発車までの時間はブラウザの時計から毎秒自動更新
